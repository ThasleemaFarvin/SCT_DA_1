# SCT_DA_1_Excel Sales Dashboard

## Project Overview
This project is an Excel-based Sales Dashboard created using the Superstore Sales dataset. It demonstrates data cleaning, data analysis, and visualization using Microsoft Excel.

## Objective
To analyze sales data and create an interactive dashboard that displays:
- Total Sales
- Total Profit
- Profit by Category
- Sales Trend Over Time
- High and Low Performers using Conditional Formatting

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting

## Features
